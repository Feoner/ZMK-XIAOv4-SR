# nice_oled (vendored)

Copy of `boards/shields/nice_oled` from
[mctechnology17/zmk-nice-oled](https://github.com/mctechnology17/zmk-nice-oled)
at commit `46f824a` (MIT, see `LICENSE`). It lives in this config repo instead of
`west.yml` so it can carry the catbus art and a few fixes. Do not also add the
upstream module to `west.yml`: both would define the same shields.

Changes for this keyboard (search for `skreecustom:` in the sources):

- `assets/catbus.c`: catbus animation frames + sleep still, generated by
  `tools/gif_to_nice_oled.py` (re-run it to change the art).
- `NICE_OLED_WIDGET_ANIMATION_PERIPHERAL_CATBUS` and `NICE_OLED_SLEEP_ART_CATBUS`
  Kconfig options.
- Sleep art fixes: the upstream code checked non-existent `NICE_PERI_VIEW_*`
  symbols (art never showed), started visible, dereferenced NULL at init, and
  `CMakeLists.txt` tested `ON_IDLE` twice instead of `ON_IDLE OR ON_SLEEP`.
- The peripheral animation pauses while the sleep art is shown.
- Dropped the unused `.ttf` font sources.
